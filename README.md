# Smart Canteen Food Demand Prediction System

## Project Overview
The Smart Canteen Food Demand Prediction System is a Machine Learning-based project designed to predict food demand in a college canteen using historical food order data. It aims to reduce food wastage, avoid food shortages, and improve food preparation planning.

## Objectives
- Predict the demand for food items in a college canteen.
- Reduce food wastage and unnecessary preparation.
- Help canteen staff plan food quantities efficiently.
- Improve inventory management and resource utilization.

## Technologies Used
- **Programming Language:** Python
- **Libraries:** Pandas, NumPy, Matplotlib, Scikit-learn
- **Platform:** Visual Studio Code / Google Colab
- **Machine Learning:** Regression-based prediction

## Project Workflow
1. Collect historical food demand data.
2. Load and preprocess the dataset.
3. Perform exploratory data analysis and visualize trends.
4. Train a Machine Learning model.
5. Predict future food demand based on the available input features.
6. Evaluate model performance and display results using graphs.

## Expected Outcomes
- Better food demand estimation.
- Reduced food wastage.
- Improved food availability.
- More efficient canteen management.

## Current Project Status
The project is under development. The dataset and model implementation will be integrated as the project progresses.
